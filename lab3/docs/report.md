# Промпт
Придумай сущность (Data Type) для фитнес-приложения, которая будет хранить заметки пользователя после тренировки. Назови её "Запись дневника". Предложи 3-4 поля разных типов (текст, дата, число, ссылка на пользователя).

# 4.2
На этой странице создай интерфейс для ведения дневника тренировок. Добавь Repeating Group для вывода всех записей из сущности "Запись дневника". Внутри ячейки выведи текст заметки, дату и оценку. Добавь кнопку "Редактировать" и "Удалить" рядом с каждой записью. Вверху страницы добавь форму для создания новой записи: Input для текста, Date Picker для даты, Input для оценки и кнопку "Сохранить". Сделай дизайн в стиле моего приложения.
